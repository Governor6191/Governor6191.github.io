See the flood model run.

This is the SAR flood model from the project below, running live on AWS. Pick a small Sentinel-1 radar crop, hit run, and the model segments the flood water and draws the polygons on the map. It runs serverless and scales to zero, so the first call after a quiet spell is a cold start and takes a little longer. What comes back is the real API answering, not a recording.

Predicted flood water. The map fits to the result once the model finishes.

The model is a U-Net (ResNet-34 encoder) that reads radar backscatter and finds open water. It works through cloud and at night, which is when optical satellites are blind and a flood map matters most. Want the detail? Read the full project writeup and the code on GitHub.
