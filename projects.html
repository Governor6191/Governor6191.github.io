Sentinel-1 SAR flood-extent pipeline.

A deep-learning segmentation pipeline that maps flood extent from radar. Trained on Sen1Floods11, validated on Hurricane Harvey over Houston against the Copernicus EMS delineation. Radar sees through cloud and works at night, so it is the data source you can use during an active storm.

Serverless SAR flood-extent API on AWS.

MLOps Serverless Infrastructure as code

The flood model deployed as a live serverless inference API. POST a Sentinel-1 scene, get back a flood mask and GeoJSON polygons. The API is asynchronous because inference can outrun API Gateway's 29 second limit, and SageMaker Serverless scales to zero, so idle cost is zero.
